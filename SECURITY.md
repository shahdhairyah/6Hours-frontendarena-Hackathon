# 🛡️ Security Policy — LEDGER

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

The LEDGER team takes the security and integrity of our codebase seriously. Because LEDGER is a **strictly client-side frontend application with zero backend servers**, no sensitive user telemetry or personal financial data is stored remotely or transmitted over the network.

If you believe you have discovered a vulnerability (such as a DOM-based XSS, prototype pollution, or dependency vulnerability):

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately to the maintainers via security advisory or maintainer email.
3. Provide step-by-step instructions to reproduce the issue.

We will acknowledge receipt within 24 hours and provide a remediation plan.
